# Ресурсы пультов

```
remotes/<id>/
  remote.json   описание пульта: фото, кнопки, экран, экраны с ячейками (схема — remotes/SCHEMA.md)
  photo.png     фото с прозрачным фоном
sprites/        картинки экранов (фоны, плитки, значки)
activity_icons/ значки активностей
theme/          таблицы стилей и значки интерфейса
i18n/           переводы
export/         README, который выкладывается вместе с ресурсами («Выгрузить ресурсы пультов…»)
```

Встроенные пульты: 900, One, 600, 650, 665, 700, 1000, 1100, 1100i.
CMake собирает каталог моделей из `remotes/*/remote.json` и встраивает ресурсы в программу;
новая папка в `remotes/` подхватывается при сборке без правки CMake.

## Фото

- Везде `photo.png`. Фото обрезаны по границам пульта и масштабированы без искажения:
  у длинных пультов высота ровно 1500 px (холст 450×1500), у широких 1000/1100/1100i
  ширина ровно 680 px (холст 680×550). Пульт по центру, остальное прозрачное.
- Пропорции 900 сверены с габаритами 222×58 мм; у остальных моделей габариты не проверялись.
- 1100 и 1100i: разные фото и зоны, экраны одинаковые. Что 1100i отличается только
  отсутствием RF-модуля — по обзорам, экраны не сравнивались.

## Что проверено

- Координаты сняты по картинкам на глаз и сверены с экраном в программе. Погрешность
  несколько пикселей, у тонких кнопок (боковые полоски 1100, цветные клавиши) больше.
- Экран `command` 1100 снят с избранных каналов Watch TV: у других активностей меняется
  содержимое панелей, а не их положение. Экран `transport` 1100 — самый грубый, `keypad` 1100 — средней точности.
- Положение плиток зависит от темы оформления пульта; везде взята стандартная тема.
- У 1000 нет экранов `command` и `keypad`: нет снимков, а раскладки 1100 не подходят
  (у 1000 нет физических боковых кнопок).
- Экран `command` у 900/One не сверен ни с одним снимком.
- У 600-серии размечен только экран команд. Связь экранных ячеек с кнопками:
  `Screen1` ↔ `SoftLeft1`, `Screen2` ↔ `SoftRight1`, `Screen3` ↔ `SoftLeft2`, `Screen4` ↔ `SoftRight2`.
- Режимы `settings`, `game`, `custom` у 1000/1100 не размечены: подсвечивается экран целиком.
- Цвета экранов 600-серии подобраны без фото экрана, их стоит сверить.

## Правки без пересборки

Рабочая папка — `resources` рядом с исполняемым файлом. При запуске программа создаёт
её и восстанавливает недостающие встроенные файлы. Существующие файлы, в том числе
изменённые, не перезаписываются. Чтобы вернуть встроенный файл, удалите его и обновите
ресурсы. Свои модели храните отдельно: из встроенной копии они не восстанавливаются.

- **Пульт → Открыть папку ресурсов пультов** — открыть папку.
- **Пульт → Обновить ресурсы пультов** — перечитать вручную. Программа и так следит за
  файлами и перечитывает их после сохранения; во время обмена с пультом — откладывает.
- **Пульт → Выгрузить ресурсы пультов…** — выгрузить текущий набор вместе с
  `HARMONY-RESOURCES.md` (из `export/`).

Ошибка во встроенном пульте (JSON, зона вне фото, размер фото не совпадает с `size`)
отменяет всё обновление: остаётся прежний корректный набор, ошибка — в строке состояния
и журнале. Ошибка во внешнем пульте пропускает только этот пульт; редактор зон
показывает такие пульты, чтобы их можно было исправить. Правка ресурсов не меняет
назначения команд в конфигурациях.

Если файл изменили одновременно в редакторе зон и в текстовом редакторе, сохранение
предлагает либо записать правки редактора поверх (остальные изменения файла остаются),
либо загрузить файл заново.

## Добавление модели

Скопируйте папку похожей модели в `remotes/<новый-id>/`, поменяйте в `remote.json`
`id` (равен имени папки) и `name`, замените фото и `hardware.size`, поправьте зоны и
экраны — в редакторе зон или вручную. После обновления ресурсов модель появится в выборе
пульта; её id сохраняется в проекте. Чтобы открыть проект с разметкой на другом
компьютере, перенесите и папку модели. Удаление папки не меняет модель проекта —
пропадают только разметка и запись.

Новая модель без `connection` получает `driver: none` и `format: none`.
Неизвестное значение отклоняет модель. `usb-hid` не добавляет поддержку новых
USB-идентификаторов и не умеет записывать. Совпадение внешнего вида не означает
совместимости протокола.

Так проверяется пульт 880: он лежит только во внешней папке `dist/win/resources/remotes/880`
и во встроенные ресурсы намеренно не добавлен.
