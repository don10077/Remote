# remote.json: схема описания пульта (schemaVersion 1)

Каждый пульт описан одним файлом `remotes/<id>/remote.json` рядом с `photo.png`.
Общих именованных раскладок нет: все экраны пульта описаны в его собственном файле.

```
{
  "schemaVersion": 1,
  "id": "900", "name": "Harmony 900",
  "capabilities": { "touch": true },
  "connection":   { "driver": "usb-net|usb-hid|hub|none", "format": "harmony-xml|device-sequence|gspm|arch14|hub-json|none" },
  "hardware":     { "image": "photo.png", "size": [w, h], "zones": [ Zone ] },
  "display":      { "rect": [x, y, w, h], "tint": "#rrggbb" },
  "tiles":        { "color": "#rrggbb", "border": "#rrggbb" },
  "screens":      [ Screen ]
}
```

## Верхний уровень

| Поле | Смысл |
|---|---|
| `id` | Совпадает с именем папки: строчные латинские буквы, цифры, `_`, `-`; начинается с буквы или цифры |
| `name` | Название в списке моделей |
| `capabilities.touch` | `true`, если экран сенсорный: плитки нажимаются щелчком. Одно значение на пульт; поле `touch` у экранов из прошлой версии переносится сюда при загрузке |
| `connection.driver` | Как программа связывается с пультом: `usb-net` — USB-сеть, адрес 169.254.1.2 (900, 1000, 1100, 1100i); `usb-hid` — USB HID (One, 600–700); `hub` — через Harmony Hub по сети; `none` — без подключения |
| `connection.format` | Формат конфигурации: `harmony-xml` — UserConfiguration.xml + IrProto.bin/SsIr.bin (900); `device-sequence` (1000, 1100, 1100i); `gspm` (One); `arch14` (600–700); `hub-json` (хаб); `none` — неизвестен. Запись на пульт реализована только для `usb-net` + `harmony-xml` |
| `hardware.image` | Фото пульта с прозрачным фоном, обычно `photo.png` |
| `hardware.size` | `[ширина, высота]` фото в пикселях. Должен совпадать с PNG, иначе модель отклоняется |
| `hardware.zones` | Физические кнопки на фото |
| `display.rect` | Светящаяся часть экрана на фото, в пикселях фото |
| `display.tint` | Основной цвет экрана (используется у 600-серии) |
| `tiles` | Оформление плиток, общее для всех экранов пульта. `area` `[x, y, w, h]` — общая зона плиток экранов без своей `grid.area`. Перекрывает `cell.color` и `cell.border` экранов. Редактор экранов пишет цвет сюда. Если у экрана задан `cell.image`, картинка главнее цвета |

## Zone (физическая кнопка)

```json
{ "id": "VolumeUp", "rect": [50, 714, 70, 74], "radius": 14, "kind": "Key" }
```

- `rect` — x, y, ширина, высота в пикселях фото от левого верхнего угла. Зона лежит внутри фото, `id` не повторяются.
- `radius` — радиус углов в пикселях; отрицательный — доля короткой стороны (`-0.5` — круг).
- `kind`: `Key` — кнопка, на которую назначаются команды, `id` — имя кнопки конфигурации (`Play`, `Number5`, `VolumeUp`); `System` — без команды (Off, Help); `ScreenActs` — открывает экран активностей; `ScreenSoft` — открывает экран команд (с `id` `Devices` или `Options` — одноимённый экран, с `id` `Soft…` — только физическая кнопка у экрана); `PagePrev`, `PageNext` — листание.
- Имена одинаковы у всех пультов. Имён, которых нет у 900, немного: `WatchTV`, `WatchMovie`, `ListenMusic`, `MoreActivities` (600-серия), `SoftLeft1..4`, `SoftRight1..4`.

## Screen

| Поле | Смысл |
|---|---|
| `id` | `devices`, `activities`, `command`, `favorites`, `transport`, `keypad` |
| `role` | `devices`, `activity`, `command`, `favorites`, `media`, `numpad` |
| `ref` | Система координат экрана `[w, h]`: 232×290 у 900/One, 172×182 у 600-серии, 320×240 у 1000/1100 |
| `grid` | `{cols, rows, gap?, area?}` — сколько плиток рисовать. `area` `[x, y, w, h]` — зона плиток в единицах `ref`: плитки раскладываются внутри неё и не закрывают служебное на фоне (часы, батарею); без неё — по всему экрану. Ячейка без `rect` ставится по `col`, `row` (с нуля) и `colSpan`, `rowSpan` (по умолчанию 1). `gap` в единицах `ref`, по умолчанию 4. Редактор обновляет сетку при сохранении, а зону плиток пишет, если её сдвинуть или растянуть на холсте |
| `centerLastRow` | Неполный последний ряд плиток центрируется |
| `background` | `{color, image, glass, header, footer}`: картинка задана и загрузилась — рисуется она, иначе заливка `color`; без `image` и `color` — чёрный прямоугольник. `glass` — «стеклянный» фон 900 с общей шапкой и подвалом: без поля он включён у экрана без `image` и без зон `header`/`footer`, `glass: false` отключает его. Зоны ниже накладываются поверх картинки или заливки |
| `background.header` | `{height, color?}`: полоса сверху высотой `height` (единицы `ref`, больше 0). Без `color` прозрачна. При прокрутке закреплена |
| `background.footer` | `{height, color?}`: полоса снизу, как `header`; закреплена |
| тело (без поля) | Всё между шапкой и подвалом, если место осталось; цвет тела — `background.color`. Плитки экрана без своей `grid.area` и без `tiles.area` раскладываются в теле. Шапка и подвал вместе должны быть ниже экрана. Зона плиток (`grid.area`, `tiles.area`) не больше тела: часть, заходящая под шапку или подвал, обрезается |
| ячейка `color`, `border` | Свои цвета заливки и рамки кнопки или плитки экрана (`ScreenKey`, `ScreenSide`, `ScreenSlot`); без них — цвета экрана/пульта |
| `cell` | `{color, border, image, shadow, text}` — стиль плиток. `image` растягивается на плитку, `shadow` — мягкая тень вправо-вниз, `text` — цвет подписи. По умолчанию заливка как у фона и белая рамка |
| `cells` | Ячейки экрана, см. ниже |
| `compose` | Экран собирается из картинок `layers` |
| `layers` | Картинки по слоям, рисуются по порядку: `{image, rect, tint?, label?, labelColor?, labelAlign?, layer?}`. `image` — путь от папки ресурсов (`sprites/...`), `rect` в единицах `ref`, `tint` перекрашивает картинку (значок текущего экрана) |
| `panel` | `{color, text}`: `color` — заливка подложек `ScreenPanel` на экране без `compose` (по умолчанию темнее `background.color`); `text` — цвет надписей экрана: заголовок, страница, часы, батарея, названия кнопок у экрана (`ScreenSide`), по умолчанию белый; на светлой шапке картинки фона — тёмный (у 600–700 `#111111`). На экранах с `compose` панели нарисованы на картинках, `color` не используется |

## Cell (ячейка экрана)

`{id, rect, radius, kind, ...}`, `rect` в единицах `ref` (или `col`/`row` по `grid`).

`kind`:
- `ScreenSlot` — плитка (активность, устройство, экранная кнопка из конфигурации);
- `ScreenKey` — кнопка на экране;
- `ScreenSide` — ячейка боковой панели или подпись над физической кнопкой;
- `ScreenLabel` — некликабельная подпись. Служебные элементы — по `id`: `Title` (или `Caption`) — заголовок, `Page` (или `PageLabel`) — «1 of 3», `Clock` — время, `Battery` — значок батареи, `Heading` — вопрос экрана активностей; цвет — `panel.text`. На «стеклянном» экране 900 (без картинки фона) заголовок, страница, часы и батарея всегда рисуются в его шапке;
- `ScreenPanel` — некликабельная подложка под остальными ячейками; `role`: `band` (полоса, может выходить за экран), `oval` (кольцо вокруг транспорта), `side` (боковая панель со скруглением `radius`). На экране без `compose` рисуется цветом `panel.color`.

Что делает кнопка (`ScreenKey`, `ScreenSide`), задаётся одним полем:
- `"key": "<id>"` — назначаемая кнопка с именем кнопки конфигурации; попадает в список назначаемых кнопок модели;
- `"goto": "<экран>"` — открывает другой экран; если такого экрана нет, кнопка только рисуется;
- `"page": -1 | 1` — листает страницу;
- `"system": true` — системная кнопка без команды;
- без поля — кнопка только рисуется.

`"button": "<id зоны>"` у `ScreenSide` связывает ячейку с физической кнопкой у экрана: она срабатывает и от физической кнопки.

## Порядок отрисовки

Фон (`layers` при `compose`, иначе `background.image`, иначе «стеклянный» фон 900 цветом `background.color`, иначе заливка), зоны `background.header`, `footer`, затем подложки `ScreenPanel` (без `compose`), затем плитки по `grid` (`cell.image` или цвет из `tiles`), поверх — ячейки `cells`. Подписи плиток, часы, «1 of 3» и подсветку программа рисует сама по конфигурации.

## Спрайты

Картинки лежат в `sprites/`. Значки в углах экрана по умолчанию белые; значок текущего экрана перекрашивается через `tint`: у 1000 зелёный `#8BAD2D`, у 1100 оранжевый `#FAA72C`.

| Файлы | Откуда |
|---|---|
| `*_900.png` (background, head, foot, tile, tile_active, tile_selected) | `tools/sprites/make900.py`, масштаб 2× от LCD 232×290 |
| `screen_600/650` | фон 600–700 с белой шапкой и вкладкой Devices: `background_600/650` + `head_600` + `tab_600`, `tools/sprites/make600.py`, ref 172×182, масштаб 2× |
| `background_600/650`, `head_600`, `tab_600`, `cross_600` | части для `screen_600/650`, тот же скрипт |
| `mmedia_1100.png` | тёмный транспорт 1100, из `mmedia.png` скриптом `tools/sprites/dark.py` |
| `cd.png` | угол справа сверху у 1100 на экране транспорта |
| `battery.png`, `energy.png` | батарея 1100 в верхней планке, до 3 делений |
| `pagination.png` | листание у 1100 внизу по центру, «1 of 3» между стрелками |
