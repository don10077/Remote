# Ресурсы пультов Harmony

Рабочая папка `resources` находится рядом с программой. Она создаётся автоматически.
При запуске и обновлении недостающие штатные файлы восстанавливаются; существующие
файлы, в том числе изменённые, не перезаписываются. Данные загружаются из этой папки.
Выбирать папку в настройках не нужно.

Изменения применяются после сохранения файла (вручную — «Пульт → Обновить ресурсы
пультов»). При ошибке остаётся прежний корректный набор. Для восстановления
штатного файла удалите его и обновите ресурсы. Свои новые модели сохраняйте отдельно:
их невозможно восстановить из встроенной копии.

## Структура

```
layouts.json              раскладки экрана (общие для всех пультов)
sprites/                  картинки для сборки экранов 1000/1100 (screens.json)
remotes/<id>/
  profile.json            описание модели
  photo.png               фото пульта с прозрачным фоном
  zones.json              кнопки на фото
  screens.json            картинки экрана (не обязателен)
```

## profile.json

| Поле | Значение |
|---|---|
| `id` | совпадает с именем папки: строчные латинские буквы, цифры, `_`, `-` |
| `name` | название в списке моделей |
| `image` | всегда `"photo.png"` |
| `size` | `[ширина, высота]` фото в пикселях, должен совпадать с PNG |
| `screen` | `[x, y, ширина, высота]` экрана на фото или `null` |
| `modes` | раскладка экрана для режима: `{"activities": "list_3", "command": "grid_2x3"}`, id из `layouts.json` |
| `driver` | `none` — без подключения; `hid` — чтение резервной копии по USB HID; `harmony900` — сетевой протокол Harmony 900 |
| `configFormat` | `unsupported` или `harmony900` |

Запись на пульт доступна только для `driver: harmony900` вместе с `configFormat: harmony900`.

## zones.json

Массив зон. Координаты в пикселях фото от левого верхнего угла:

```json
{ "id": "VolumeUp", "rect": [50, 714, 70, 74], "radius": 14, "kind": "Key" }
```

`rect` — x, y, ширина, высота. `radius` — радиус углов; отрицательный — доля
короткой стороны (`-0.5` — круг). `kind`: `Key` (кнопка, на которую назначаются
команды, `id` — имя кнопки конфигурации), `System`, `ScreenActs`, `ScreenSoft`,
`PagePrev`, `PageNext`. Зона должна лежать внутри фото, `id` не повторяются.

## Новая модель

Скопируйте папку похожей модели в `remotes/<новый-id>/`, поменяйте в `profile.json`
`id` и `name`, замените фото (и `size`) и поправьте зоны. Модель появится в выборе
пульта. Совпадение внешнего вида не означает, что протокол связи тот же.
