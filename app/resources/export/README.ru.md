# Ресурсы пультов Harmony

Рабочая папка `resources` находится рядом с программой. Она создаётся автоматически.
При запуске и обновлении недостающие штатные файлы восстанавливаются; существующие
файлы, в том числе изменённые, не перезаписываются. Данные загружаются из этой папки.

Изменения применяются после сохранения файла (вручную — «Пульт → Обновить ресурсы
пультов»). При ошибке в штатном пульте остаётся прежний корректный набор; пульт, добавленный
вами, с ошибкой просто не появится в списке, а редактор зон покажет причину. Для
восстановления штатного файла удалите его и обновите ресурсы. Свои модели храните
отдельно: их невозможно восстановить из встроенной копии.

## Структура

```
sprites/                  картинки экранов (фоны, плитки, значки)
remotes/<id>/
  remote.json             описание пульта: фото, кнопки, экраны
  photo.png               фото пульта с прозрачным фоном
```

## remote.json

```json
{
  "schemaVersion": 1,
  "id": "my-remote",
  "name": "Мой пульт",
  "capabilities": { "touch": false },
  "connection": { "driver": "usb-hid" },
  "hardware": {
    "image": "photo.png",
    "size": [450, 1500],
    "zones": [
      { "id": "VolumeUp", "rect": [50, 714, 70, 74], "radius": 14, "kind": "Key" }
    ]
  },
  "display": { "rect": [112, 216, 228, 284] },
  "screens": []
}
```

| Поле | Значение |
|---|---|
| `id` | совпадает с именем папки: строчные латинские буквы, цифры, `_`, `-` |
| `name` | название в списке моделей |
| `hardware.size` | `[ширина, высота]` фото в пикселях, должен совпадать с PNG |
| `hardware.zones` | кнопки на фото |
| `display.rect` | `[x, y, ширина, высота]` экрана на фото |
| `connection.driver` | как программа связывается с пультом: `usb-net` — USB-сеть (900, 1000, 1100, 1100i); `usb-hid` — USB HID (One, 600–700); `mh` — MyHarmony по сети; `hub` — через Harmony Hub; `none` — без подключения. Пустое поле или поля нет — значение каталога моделей; заданное здесь значение важнее каталога, и для модели, которой в каталоге нет, это единственный способ задать связь. Неизвестное имя отклоняет модель |
| `screens` | экраны пульта с плитками и ячейками; проще всего создать в редакторе зон |

Право записи на пульт решает справочник моделей: remote.json выбирает только способ связи,
но не то, можно ли писать. Формат конфигурации определяется семейством справочника и данными
прочитанного файла; профиль новой модели не наследует знания и право записи от похожей модели.

Зона: `rect` — x, y, ширина, высота в пикселях фото от левого верхнего угла.
`radius` — радиус углов; отрицательный — доля короткой стороны (`-0.5` — круг).
`kind`: `Key` (кнопка, на которую назначаются команды, `id` — имя кнопки конфигурации),
`System`, `ScreenActs`, `ScreenSoft`, `PagePrev`, `PageNext`. Зона должна лежать
внутри фото, `id` не повторяются.

## Новая модель

Скопируйте папку похожей модели в `remotes/<новый-id>/`, поменяйте в `remote.json`
`id` и `name`, замените фото (и `hardware.size`) и поправьте зоны и экраны в редакторе
зон. Модель появится в выборе пульта. Совпадение внешнего вида не означает, что
протокол связи тот же.
