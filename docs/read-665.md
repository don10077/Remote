# Как снять копию настроек Harmony 665

Понадобится компьютер с Windows 10 или 11, Harmony 665 и USB-кабель с передачей данных.
Чтение не меняет настройки пульта.

1. Запустите сборку Harmony, которую мы вам прислали. Если это ZIP, распакуйте его целиком
   и запустите `harmony.exe` из распакованной папки. Если прислали `-setup.exe`, установите
   программу и откройте **Harmony**.
2. Закройте программу Logitech Harmony, если она запущена, в том числе её значок возле
   часов. Подключите пульт напрямую к USB компьютера.
3. В нашей программе откройте **Пульт → Файлы конфигурации — все модели…**, в списке
   выберите **Harmony 665** и нажмите **Прочитать конфигурацию в файл…**.
4. Выберите **Рабочий стол**, оставьте предложенное имя и нажмите **Сохранить**.
   Дождитесь сообщения о завершении чтения, затем отключите пульт.
5. Пришлите нам одним вложением файл `Harmony-665-….remote.json` с рабочего стола.

Если программа покажет ошибку, пришлите снимок окна с её текстом. Если файл всё-таки
появился, приложите и его: программа сохраняет копию перед проверкой, и она может помочь
нам разобраться. Используйте только кнопку чтения.

В английском интерфейсе: **Remote → Configuration files — all models… →
Read configuration to file…**.
